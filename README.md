# Android TV 应用发布仓库

本仓库用于存放和更新 Android TV / N1 电视盒子的 APK 应用文件。

## 📦 最新版本下载

请前往 [Releases 页面](../../releases) 获取最新的 `.apk` 安装包。

## 🚀 安装方法

1. 在 Releases 页面下载对应的 APK 文件到 U盘。
2. 将 U盘 插入电视盒子或 Android TV 设备。
3. 打开电视自带的文件管理器，找到 APK 文件点击安装即可。

## 📝 更新日志

请在具体的 [Release 页面](../../releases) 查看每个版本的详细更新说明。
